# Quick Start Commands

## After installing Node.js from https://nodejs.org/

### Step 1: Navigate to project
```
cd "c:\Users\Pavan\Desktop\portfolio website\app\frontend"
```

### Step 2: Install dependencies
```
npm install
```

### Step 3: Start development server
```
npm start
```

### Step 4: Build for production (when ready)
```
npm run build
```

---

**That's it! Your portfolio will open in the browser automatically.**

Visit: http://localhost:3000

---

## File Locations

**Edit your information in:**
- `src/mock.js` - All your data (profile, skills, projects, etc.)

**Main components:**
- `src/App.js` - Main entry point
- `src/components/` - All page sections

**Styles:**
- `src/index.css` - Global styles
- `src/App.css` - Component styles
- `tailwind.config.js` - Tailwind configuration

---
